## Least Privilege by Default

Give each agent only the access its workflow needs. Separate credentials per agent make it clear what touched which system and let you revoke access without disrupting anything else running alongside it.

## Approvals for Risky Actions

Moving money, deleting records, or emailing customers should pause for a human decision. An approval step adds seconds to a run but removes the scenario where one bad instruction causes lasting damage.

## Audit Everything

Log every tool call with its inputs, outputs, and the reasoning behind it. A complete trail turns incidents into short investigations and gives security teams the evidence they need before approving wider automation.

## Review Access Regularly

Workflows change, and permissions granted for last quarter's project tend to linger. A regular access review keeps agents aligned with current needs, which keeps automation both useful and trustworthy.
