## About this role

This internship focuses on the interfaces people use to create, monitor, and trust their agents. You will work with designers and engineers on real features and learn to turn complex system states into clear, fast, accessible screens.

## Responsibilities

- Build interface components for the agent builder
- Turn designs into responsive, accessible pages
- Visualize run history, logs, and status updates
- Write tests and fix bugs across the web app
- Share feedback in reviews and planning sessions

## Requirements

- Solid grounding in HTML, CSS, and modern JavaScript
- Some experience with a component framework
- Curiosity and care for small interface details

## Nice to Have

- A portfolio of personal or open-source projects
- Interest in data visualization or motion
- Familiarity with design tools and handoff workflows
